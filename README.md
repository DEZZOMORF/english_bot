# English daily update bot

Telegram-бот для групи: щодня о 20:00 (за Києвом) нагадує написати **daily update**, тобто як минув день, і показує, хто не написав апдейт учора та скільки днів поспіль.

## Як це працює

- **Апдейт** = будь-яке повідомлення людини в групі (текст, фото, стікер тощо). Команди `/…`, службові повідомлення та повідомлення від ботів не рахуються.
- **День** = календарна доба 00:00–23:59 за `BOT_TIMEZONE`.
- **Нагадування** о `REMINDER_TIME` містить список тих, хто не пише апдейт `MIN_MISSED_DAYS` (за замовчуванням 3) і більше днів поспіль, до вчора включно. Людей згадано через @нікнейм, а якщо його немає, через ім'я-посилання, тож вони отримають сповіщення. `/stats` показує той самий список у будь-який момент.
- **Учасники.** Бот реєструє людину, коли вона вперше напише будь-яке повідомлення в групі. Хто ще нічого не писав, того бот не бачить: Telegram не дає ботові переглянути список учасників групи.
- Лічба пропусків починається з наступного дня після першого повідомлення людини. Хто виходить із групи, зникає зі звіту, а якщо повернеться й напише, лічба почнеться заново.

Команди в групі: `/stats`, `/help`.

## Налаштування бота в Telegram

1. Створіть бота в [@BotFather](https://t.me/BotFather) і отримайте токен.
2. **Вимкніть privacy mode:** `/setprivacy` → бот → `Disable`. Інакше бот не бачитиме звичайних повідомлень. Замість цього можна зробити бота адміністратором групи; адміністратор ще й бачить, хто виходить і заходить.
3. Додайте бота в групу. Якщо privacy mode змінили, коли бот уже був у групі, видаліть його з групи й додайте знову.

## Конфігурація (`.env`)

| Змінна | За замовчуванням | Опис |
|---|---|---|
| `BOT_TOKEN` | — | токен від BotFather |
| `BOT_TIMEZONE` | `Europe/Kyiv` | часовий пояс для доби й нагадування |
| `REMINDER_TIME` | `20:00` | час нагадування `HH:MM` |
| `MIN_MISSED_DAYS` | `3` | з якої кількості днів поспіль без апдейту людина потрапляє в список |
| `DB_PATH` | `data.db` | шлях до SQLite (у Docker: `/data/data.db`) |

## Локальний запуск

```sh
python3.12 -m venv .venv && .venv/bin/pip install -r requirements-dev.txt
.venv/bin/python -m pytest
set -a; . ./.env; set +a; .venv/bin/python -m bot.main
```

## Деплой (VPS)

```sh
rsync -a --exclude .env --exclude .venv --exclude .git ./ npa:/opt/english-bot/
ssh npa 'cd /opt/english-bot && docker compose build && docker compose up -d'
```

`.env` лежить лише на хості (`/opt/english-bot/.env`, `chmod 600`). Дані зберігаються в docker volume `englishbot_data`. Щоденний бекап робить `deploy/englishbot-backup.sh`, який встановлено як `/usr/local/bin/englishbot-backup.sh` і запускається cron о 04:15. Бекапи лежать у `/opt/english-bot/backups`, зберігаються останні 14.
